# 數據中台管理系統 · 交互原型

投注交易數據中台的交互原型，供產品組評審與協作使用。配色沿用原站 `192.168.10.51:7080`，字體按產品基線規範（Outfit + 系統中文）。

**原型版本：V1.0.0** ｜ 發布日期：2026-11-04 ｜ 框架參考：V1.5.5

## 文件結構

```
index.html      框架頁 —— 頂部工具條 + iframe，切換管理面 / 產品基線
dmp.html        管理面 —— 10 個業務頁面，可獨立打開
rule.html       產品基線 —— 13 章規範文檔，可獨立打開
assets/
  app.css       共用樣式（設計變量、管理面、組件、響應式）
  core.js       公共運行庫（版本常量、圖標、toast、彈窗、分頁）
  rule.css      規範頁專屬樣式
_fonts/         Outfit 六檔字重 woff2 + outfit.css
```

三個 HTML 互不依賴，任一個都能單獨打開。`index.html` 支持 `#dmp` / `#rule` 直接進入指定頁。

## 本地預覽

框架頁用 iframe 加載子頁，`file://` 直接雙擊會被瀏覽器的跨域策略攔截。起一個本地靜態服務：

```bash
python -m http.server 8000
```

然後訪問 `http://127.0.0.1:8000/index.html`。

## 功能覆蓋

**管理面**（10 頁）

| 分組 | 頁面 |
| --- | --- |
| 事件總覽 | 事件總覽 |
| 事件管理 | 事件列表、事件分類、事件複核、投注類係數調控 |
| 商戶管理 | 商戶列表 |
| 系統設置 | 用戶管理、角色管理、操作日誌 |
| 登錄與認證 | 登錄頁 |

二級頁面：事件審核詳情（基本資訊 / 市場 / 倉位情況 / 欄位映射）、商戶權限設定（類型 / 分類 / 數據源 / 過濾事件）、新增角色。

**彈窗與交互**：新增分類 / 商戶 / 用戶 / 角色、審核（通過 / 棄用）、國家過濾（六大洲 230 國）、Google 驗證綁定（二維碼 + 5 分鐘倒計時）、賬號下拉菜單、確認框、Toast。

**產品基線**（13 章）：基線總覽、全局規範（配色 / 字體字號 / 間距圓角）、公共說明（加載 / 空態 / 提示）、組件與規範（按鈕 / 輸入 / 表格 / 分頁 / 標籤 / 狀態）。

## 說明

- 演示數據為 mock，不含真實後端，任意帳密可進入。
- 登錄流程參照原站的 RSA-OAEP 加密 + challenge 機制設計，原型內為模擬實現。
- Google 驗證綁定中的二維碼為 SVG 示意圖，不可真實掃碼。
