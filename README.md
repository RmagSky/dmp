# 數據中台管理系統 · 交互原型

投注交易數據中台的交互原型，供產品組評審與協作使用。配色沿用原站 `192.168.10.51:7080`，字體按產品基線規範（Outfit + 系統中文）。

**原型版本：V1.4.0** ｜ 發布日期：2026-11-09

## 在線訪問

主入口（Cloudflare Workers）：**https://dmp.arthems.workers.dev/**

備用入口（GitHub Pages）：**https://rmagsky.github.io/dmp/**

直接打開即可，無需本地環境。單頁入口：

| 頁面 | Cloudflare | GitHub Pages |
| --- | --- | --- |
| 管理面 | `https://dmp.arthems.workers.dev/dmp` | `https://rmagsky.github.io/dmp/dmp.html` |
| 產品基線 | `https://dmp.arthems.workers.dev/rule` | `https://rmagsky.github.io/dmp/rule.html` |

Cloudflare 端省略 `.html` 後綴，帶後綴的地址會自動 307 跳轉到無後綴路徑。GitHub Pages 需保留後綴。

## 文件結構

```
index.html      框架頁 —— 頂部工具條 + iframe，切換管理面 / 產品基線
dmp.html        管理面 —— 16 個業務頁面，可獨立打開
rule.html       產品基線 —— 14 章規範文檔，可獨立打開
assets/
  app.css       共用樣式（設計變量、管理面、組件、響應式）
  core.js       公共運行庫（版本常量、圖標、toast、彈窗、分頁）
  entity.js     多源實體標識庫原型（數據、四個頁面與彈窗）
  rule.css      規範頁專屬樣式
api-detail.html  OpenAPI 調用詳情子頁（由商戶列表「更多」進入，iframe 嵌入）
api-alarm.html   API 推送異常子頁（系統設置菜單，iframe 嵌入）
_fonts/         Outfit 六檔字重 woff2 + outfit.css
```

三個 HTML 互不依賴，任一個都能單獨打開。`index.html` 支持 `#dmp` / `#rule` 直接進入指定頁。

## 本地預覽

框架頁用 iframe 加載子頁，`file://` 直接雙擊會被瀏覽器的跨域策略攔截。起一個本地靜態服務：

```bash
python -m http.server 8000
```

然後訪問 `http://127.0.0.1:8000/index.html`。

## 協作流程

主線只有 `main`，所有人直接在主線上工作。每次動手前拉取，上傳前合併並驗證：

```bash
git pull --rebase origin main          # 1 拉取上游
git log --oneline HEAD..origin/main    # 2 檢查新提交
git diff --stat HEAD origin/main       #   上游改了哪些文件
git merge origin/main                  # 3 合併
git add <衝突文件> && git rebase --continue   # 4 衝突修正
git add -A && git commit -m "feat(範圍): 摘要"
git push origin main                   # 5 上傳更新
```

推送後 GitHub Pages 自動重建，約 1 分鐘生效。完整規則見線上規範頁 5.1。

## 說明

- 演示數據為 mock，不含真實後端，任意帳密可進入。
- 登錄流程參照原站的 RSA-OAEP 加密 + challenge 機制設計，原型內為模擬實現。
- Google 驗證綁定中的二維碼為 SVG 示意圖，不可真實掃碼。
- 倉庫根目錄的 `.nojekyll` 用於禁用 Jekyll 構建，否則 `_fonts/` 會被忽略導致字體 404。
